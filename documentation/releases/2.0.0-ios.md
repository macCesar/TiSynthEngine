# iOS 2.0.0 release preparation

Status: prepared, not published. Proposed tag: `ios-2.0.0`. Proposed title: iOS 2.0.0. The implementation is on `main`.

TiSynth 2.0.0 introduces a sound-based API. Define a sound once with `createSound({ sound, playback })`, then call `explosion.play()` wherever the app needs it. The `sound` object contains synthesis settings; `playback` contains default notes, duration and playback type.

```javascript
var synth = require('ti.synthengine')
var W = synth.getContract().waveTypes

synth.start({ maxVoices: 16 })

var explosion = synth.createSound({
  sound: { waveType: W.NOISE, volume: 0.2, attack: 2, release: 100 },
  playback: { type: 'tone', frequencies: [80], duration: 250 }
})

explosion.play()
explosion.play({ volume: 0.1 })
```

## The new interface

- `createSound()` creates a reusable definition without starting audio or reserving a voice.
- `sound.play()` plays a tone, chord, repetition, pattern or held note according to its `playback` settings. Pass notes or synthesis settings to change just that execution.
- `sound.noteOn()` starts one held note and returns a control with `update()` and `noteOff()`.
- `sound.set({ sound, playback })` validates an atomic change to the stored definition. Active executions keep their settings. `sound.getPreset()` returns an independent copy.
- Repetitions return `update()` and `stop()`. Patterns also have `getState()` and an `end` event. Applications do not need to manage native playback identifiers.
- `setProcessing()` configures shared effects with delay `time` and reverb `decay` in milliseconds. `setVolume(number)` and `setTempo(number)` accept global scalar values.

Playback controls become invalid after shutdown and cannot affect a restarted engine. Sound definitions remain reusable. This release also fixes retention of held-note ID aliases and adds checks for native validation, setting resets and memory lifetimes.

Existing playback calls remain supported with their signatures, return values, identifiers and events. Native rendering and timing behavior are preserved. Update metadata checks from `apiVersion` to `version`; the installed module has one version. TypeScript declarations and the runnable example describe the new interface.

Read the [Sound API](../sound-api.md) for properties, units and return values. The [validation report](../sound-api-validation.md) records acoustic comparisons, performance measurements and their limits.

Requires Titanium SDK 13.2.0.GA or later and iOS 15 or later. Download `ti.synthengine-iphone-2.0.0.zip`.
