# iOS 2.0.0 release preparation

Status: prepared, not published. Proposed tag: `ios-2.0.0`. Proposed title: iOS 2.0.0. The implementation is on `main`.

TiSynth 2.0.0 adds reusable sounds. Keep a sound definition and play it with different notes or temporary settings. Held notes, repetitions and patterns return controls for updating or stopping that execution.

- [x] Make `set()` validate the complete change before applying it. Active executions keep their settings.
- [x] Invalidate playback controls after shutdown so they cannot affect a restarted engine.
- [x] Keep existing playback signatures, return values, identifiers, events and native audio behavior.
- [x] Use the installed module's `version` throughout runtime metadata. Update TypeScript declarations and examples.
- [x] Fix retention of held-note ID aliases and add regression checks for native validation, setting resets and memory lifetimes.

Update metadata checks from `apiVersion` to `version`. Existing playback calls remain supported. The [Sound API](../sound-api.md) documents the new interface and maps the existing methods. The [validation report](../sound-api-validation.md) records acoustic comparisons, performance measurements and their limits.

Requires Titanium SDK 13.2.0.GA or later and iOS 15 or later. Download `ti.synthengine-iphone-2.0.0.zip`.

## Publication checks

Build both platforms from the exact clean commit on `main` that will receive the release tags. Refresh packaged documentation, check ZIP integrity and versions, and record SHA256 digests. Publish Android and iOS separately using the proposed tags above.
