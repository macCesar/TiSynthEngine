# iOS 2.0.0

TiSynth 2.0.0 introduces a reusable sound API:

```javascript
var synth = require('ti.synthengine')
var W = synth.getContract().waveTypes

var bell = synth.createSound({
  sound: { waveType: W.SINE, volume: 0.25, release: 120 },
  playback: { notes: ['A4'], duration: 400 }
})

// After engine startup:
bell.play()
bell.play({ notes: ['C5'] })
```

- Separate synthesis settings (`sound`) from default notes and timing (`playback`).
- Use `play()` for finite sounds, chords, repetitions and patterns. Use `noteOn()` for held notes.
- Update definitions with atomic `set()` changes and retrieve them with `getPreset()`.
- Update or stop playback through returned controls, without managing native identifiers.
- Configure shared effects through `setProcessing()`, with delay and reverb times in milliseconds.
- Preserve existing playback calls and native rendering behavior.
- Fix held-note identifier retention and invalidate playback controls after shutdown.

Runtime metadata now uses `version`; update checks that read `apiVersion`. Documentation, TypeScript declarations and the runnable example cover the new interface.

See the [API reference](https://github.com/macCesar/TiSynthEngine/blob/main/documentation/sound-api.md), [upgrade guide](https://github.com/macCesar/TiSynthEngine/blob/main/documentation/upgrade-2.0.0.md) and [validation results and limits](https://github.com/macCesar/TiSynthEngine/blob/main/documentation/sound-api-validation.md).

Requires Titanium SDK 13.2.0.GA or later and iOS 15 or later. Includes device, simulator and Mac Catalyst builds. Download `ti.synthengine-iphone-2.0.0.zip`.
